# 🧪 Jake's Sandbox

A lightweight browser-based coding sandbox for writing, running, and experimenting with code.

> Built as a personal project to make coding and experimenting with different languages simple and accessible.

---

## ✨ Features

* 🐍 **Python** execution
* ⚙️ **C++** compilation and execution
* ☕ **Java** support
* 🦀 **Rust** support
* 📝 Code editor with syntax highlighting
* 📁 File explorer and multiple files
* 💻 Built-in terminal/output panel
* ▶️ Run and compile controls
* ⛔ Stop execution
* 💾 Save and download your code
* 🎨 Customizable themes
* ⌨️ Keyboard shortcuts
* 🌐 Runs directly in your browser

---

## 🧑‍💻 Suppo*rted Languages*

### Python

Run Python directly in the browser.

```python
name = input("What is your name? ")
print(f"Hello, {name}!")
```

### C++

Write, compile, and run C++ programs from the sandbox.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello from C++!" << endl;
    return 0;
}
```

### Java

Write and run Java programs directly from the coding environment.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello from Java!");
    }
}
```

### Rust

Experiment with Rust code from the same environment.

```rust
fn main() {
    println!("Hello from Rust!");
}
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Jake1427/jakes-sandbox.git
```

Then open the project folder and launch:

```text
index.html
```

You can also serve the folder through a local web server if your browser blocks certain resources when opening the HTML file directly.
